# movie-csv-tinymm

Ce projet contient deux scripts permettant d'exporter les films et les séries dans un fichier CSV compatible avec TinyMediaManager.

## Structure du projet

- **Koromerzhin-Movie-CSV/** : Script et modèles pour l'export des films.
- **Koromerzin-TV-CSV/** : Script et modèles pour l'export des séries.

Chaque dossier contient :
- `list.jmte` : Modèle d'export au format JMTE.
- `template.conf` : Fichier de configuration du template.

## Utilisation

1. Placez les scripts et modèles dans le dossier de votre choix.
2. Configurez les fichiers selon vos besoins.
3. Exécutez le script pour générer le fichier CSV compatible avec TinyMediaManager.
